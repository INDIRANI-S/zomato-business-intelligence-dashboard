# Zomato Business Intelligence Dashboard

## Project Overview
This project analyses Zomato business data using SQL, Power BI and DAX to uncover customer behaviour, restaurant performance and revenue trends.

## Tools Used
- SQL
- Power BI
- DAX

## Key Highlights
- Cleaned and analysed restaurant and sales data.
- Built an interactive Power BI dashboard.
- Created KPIs, slicers and dynamic visuals.
- Analysed revenue, customer behaviour and restaurant performance.
- Generated business insights for decision-making.
